## ✨ Why CBM?

- 🎞️ Plays many popular video and audio formats
- 🖥️ Clean fullscreen movie experience
- ⚡ Smooth 4K/8K playback on supported Macs
- 💬 Advanced subtitle controls with quick `CC` toggle
- 📚 Beautiful library with thumbnails, favorites, and continue watching
- 🔎 Seek bar preview thumbnails
- 🎛️ Fine Tune controls for picture, sound, speed, and sync
- 📺 Cast options for compatible devices
- 🪟 Mini Player and Picture-in-Picture
- 🎨 Premium themes and polished macOS design

## 🎥 Playback Features

- ▶️ Play, pause, seek, previous, next, forward, and rewind
- ⏩ Playback speed controls
- 🧭 Chapter navigation
- 🔁 Loop and A-B repeat
- 🖥️ Fullscreen playback with custom controls
- 🪟 Picture-in-Picture
- 📌 Mini Player Pro
- 📸 Snapshot capture
- 📊 Media inspector and playback details

## 🖼️ Video Quality

- 🌈 HDR/EDR display support on compatible Macs
- 🔍 High-quality video scaling
- 🎚️ Brightness, contrast, saturation, hue, gamma, and sharpness controls
- 🧼 Denoise, deband, and deinterlace options
- 🖼️ Smart thumbnails for library posters and seek previews
- 🎬 Better handling for large high-bitrate movie files

## 🔊 Audio Features

- 🔈 Volume control up to 200%
- 🎧 Audio track selection
- 🎚️ Audio sync delay adjustment
- 🎼 Audio equalizer tools
- 🌐 Preferred audio language setting
- 🎵 Audio-only playback view
- 📊 Audio visualizer

## 💬 Subtitle Features

- `CC` quick subtitle on/off button
- Embedded subtitle track selection
- External subtitle file loading
- Secondary subtitle support
- Subtitle sync adjustment
- Subtitle size, color, font, style, and position controls
- Online subtitle search support
- Support for text and bitmap subtitle types

## 📚 Smart Library

- ➕ Add files or folders

- 🧱 Grid and list views
- ⭐ Favorites
- ▶️ Continue Watching

- AirPlay-style playback support
- Chromecast-style device support
- Local network device discovery
- Local streaming support for compatible receivers

Availability depends on your device, network, file type, and system permissions.

## 🔐 Optional Online Features

### TMDB Artwork

TMDB artwork is optional. If configured, CBM can use online movie artwork for library posters. Without TMDB, CBM uses real video-frame thumbnails from your files.

### Online Subtitles

CBM can search online subtitles when configured. Local subtitle files and embedded subtitle tracks work without online subtitle search.

## 💻 System Requirements

- macOS 14.6 or later
- Apple Silicon or Intel Mac, depending on the app build provided
- Extra performance is recommended for 4K HDR, remux, and very large movie files

## ⬇️ Download & Install

1. Download the latest CBM Media Player release.
2. Open the downloaded app package.
3. Move **CBM Media Player** to your **Applications** folder.
4. Open the app and add media files or folders to your library.

If macOS blocks the first launch, open **System Settings → Privacy & Security** and allow CBM Media Player.

## 🧹 Reset & Troubleshooting

If thumbnails, resume history, subtitles, or settings look wrong, use the built-in reset tools from settings:

- Clear thumbnail cache
- Clear online artwork cache
- Clear resume history
- Clear bookmarks
- Clear watch statistics
- Clear all app data

## ❤️ Made For Movie Lovers

CBM Media Player is designed for users who want a modern macOS player with a clean interface, powerful playback controls, and a library experience that feels ready for large movie collections.
