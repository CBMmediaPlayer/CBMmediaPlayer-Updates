## Features

- 🎬 Plays every video format — MKV, MP4, AVI, MOV, WEBM, WMV, OGG and more
- 🔊 Full audio support — Dolby Atmos, DTS, TrueHD, AAC, FLAC
- 📺 DLNA casting — cast to your TV or projector on the same network
- 📱 Apple TV — cast via macOS Screen Mirroring
- 📝 Subtitle support — SRT, ASS, SSA, PGS, embedded and external
- 🎨 Themes — gradient accent themes across the whole UI
- 📚 Library — thumbnail previews, continue watching, favorites
- 🔁 Playlist support
- 🖼️ Picture-in-Picture and mini player
- 💾 Resume playback — picks up exactly where you left off
- 🔇 Audio sync, speed control, equalizer
